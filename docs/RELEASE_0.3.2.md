# TDL Media 0.3.2

- 修复“扫描新增”和“重扫历史”在本机时间有偏差时长时间无响应。扫描复用应用的 HTTPS 校时、代理和会话连接，不再调用缺少这套校时逻辑的外部导出进程。
- 校时后使用单调计时推进客户端时间，运行中调整系统时间不会重复叠加旧偏差。
- 扫描连接或分页连续两分钟无响应时结束并显示错误；正常持续读取的大历史不受总时长限制。失败和取消保留已有索引。
- 增量游标包含普通文本消息，避免没有新媒体时重复读取同一段历史；保留话题、日期及最近 N 条媒体筛选。
- 修复取消登录可能误清除旧会话的问题，仅在新账户关联保存成功后清理旧会话。

## 升级

在“设置 → 检测更新”升级，或下载 `TDL-Media-windows-x64-0.3.2.zip` 解压使用。账户、索引、规则、任务和下载文件保留。

## 验证

- Go 测试、Go vet、18 项前端测试、生产构建和 Windows 编译通过。
- 模拟本机时间快、慢 10 分钟及 24 小时，以及运行中校准时间；覆盖分页、空结果、已删除消息、增量游标、取消、超时、历史重扫及下载标记保留。
- 使用授权账户的测试聊天完成真实增量扫描、历史重扫、再次增量扫描及最近 2 条媒体测试，单次约 2～4 秒。未发送消息或下载媒体文件。
- 大型真实聊天、不同网络代理及 Windows 10 环境尚未完成实测。
