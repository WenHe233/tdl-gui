# TDL Media 0.3.1

- 修复刷新聊天列表报“聊天分页未前进”、Telegram 分组无法载入的问题。
- 完整列表、空列表和已达到总数的末页在本地结束分页，避免底层分页器在结束后重复请求相同游标。
- 末页不再依赖下一页游标，因此末尾聊天缺少消息或无法访问时也能正常结束；真正的分页循环和网络错误仍会报告，失败时保留已有缓存。

## 升级

0.2.0 及以上版本可在“设置 → 检测更新”升级，也可下载 `TDL-Media-windows-x64-0.3.1.zip` 解压使用。账户、规则、媒体索引、下载任务和下载文件保留。

## 验证

新增测试复现 0.3.0 的失败，覆盖单页完整列表、空列表、250 个聊天分页、短末页、空末页、末尾不可访问聊天、真实循环、网络错误及取消请求。Go 测试、Go vet、18 项前端测试、生产构建和 Windows 编译通过。真实账户分组同步尚未完成验收。
