# TDL Media 0.3.0

- 新增 Telegram 风格竖向分组栏，同步已有分组的名称、图标、顺序、成员和置顶聊天，支持普通分组和已加入的共享分组。
- 聊天列表支持最近消息时间和名称排序，默认最近消息优先。进入账户和手动刷新时更新；只保存最近消息时间，不保存正文或自动扫描媒体。
- 媒体栏新增正序、倒序设置，支持双向分页及最近 N 条筛选，浏览顺序与下载顺序分别保存。
- 登录页新增“删除登录信息”。移除账户列表项及本地会话，保留索引、规则、任务和下载文件；重新登录同一 Telegram 账户后恢复历史数据。
- 空状态提示与“扫描新增”“重扫历史”按钮名称统一。
- 下载入口及任务面板显示总速度，任务和文件详情显示各自速度、已下载大小。速度按最近 2 秒的文件写入增量估算，每 500 毫秒更新。

## 下载与升级

下载 `TDL-Media-windows-x64-0.3.0.zip` 并解压，运行 `tdl-media-gui.exe`，保留同目录的 `tdl-media.exe`。0.2.0 用户可通过设置中的“检测更新”升级。tdl 引擎继续使用 v0.20.4。

旧数据库会自动增加目录缓存和账户移除记录，已有媒体索引、规则和任务保留。分组在 Telegram 客户端中管理，本应用读取同步结果。

## 验证范围

Go 测试、Go vet、18 项前端测试、前端生产构建和 Windows 便携版构建通过。新增测试覆盖分组筛选、250 条媒体的双向分页、最近 N 条、账户删除与身份匹配恢复、加密会话副本清理、速度平滑及重试。

使用 0.2.0 和 0.3.0 正式 worker 在独立目录验证升级，250 条媒体索引、固定清单及下载任务保留，账户移除后重启和排序设置持久化通过。

界面使用模拟数据检查 980×650 与 1360×850 布局、分组切换、消息顺序、删除确认、扫描提示和速度详情。未完成真实 Telegram 账户下载联调及 Windows 10 / 不同系统缩放比例的设备验证。
