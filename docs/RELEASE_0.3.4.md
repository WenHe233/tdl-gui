# TDL Media 0.3.4

- 修复 Windows 下载中速度持续显示为 0 的问题。通过文件句柄读取实时大小，保留最近 2 秒的平滑统计；暂停和结束后归零，小文件完成后仍计入总速度。
- 下载默认改为每文件 8 线程、同时 4 个文件、连接池 8。设置中可修改线程、并发、连接池、启动间隔和重试次数，并恢复推荐参数。实际速度取决于网络、代理和 Telegram。
- 设置窗口重新划分为下载、网络、存储、引擎、应用更新五个分类，支持字段校验、批量保存、未保存修改提醒和键盘操作。
- 代理、NTP、重连超时、下载目录、最低剩余空间和缓存上限可编辑。下载配置用于后续启动或恢复的任务；当前任务及自动重试继续使用原配置。网络配置用于后续新建连接。
- 限制下载日志缓冲，任务详情保留有长度限制的引擎错误信息，便于定位失败原因。

## 升级

在“设置 → 应用更新”检测更新，或下载 `TDL-Media-windows-x64-0.3.4.zip` 解压使用。旧版本保存的参数、账户、媒体索引和固定下载清单保留；新增设置使用默认值。新下载目录不改变已有清单的目标路径。

速度仍是文件增长量估算，多线程乱序写入时不代表精确网络流量。连接池 0 为不限制，缓存上限 0 为不自动清理，重连超时 0s 为不限制。

## 验证

- Go 全量测试、Go vet、31 项前端测试、前端生产构建和 Tauri Windows 编译通过。
- Windows 子进程持续写入未关闭文件时，完成前已能报告非零速度；覆盖并发、重命名、小文件、暂停恢复、重试参数快照及日志缓冲。
- 1360×850、980×650 布局检查通过，无横向溢出；实际 Windows GUI 到 JSON-RPC、SQLite 的设置保存验证通过。
- 0.3.3 到 0.3.4 隔离升级验证通过：已有配置保留、新参数默认值、批量校验、重启持久化、媒体和任务记录、清单目标路径均正确。
