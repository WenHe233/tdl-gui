# 测试与真实账户联调

## 自动测试

```powershell
$env:GOMODCACHE="$PWD\.cache\gomod"
$env:GOCACHE="$PWD\.cache\gobuild"
go test ./...
Set-Location gui
npm ci --cache .cache\npm
npm run build
```

自动测试覆盖日期与组合筛选、同聊天去重、任务总量限制、Windows 路径清理、五万条媒体预览、SQLite 工作流、tdl 下载清单、文件结果核对和引擎校验文件解析。

## 专用测试聊天准备

请在收藏夹或私有测试群依次放入：

1. 一张 JPG 和一张 PNG。
2. 一个短 MP4、一个音频或语音。
3. 一个 PDF 和一个 ZIP。
4. 一组包含 2–3 张图片的相册。
5. 将第一张 JPG 再转发一次，用于同聊天去重。
6. 一个超过设定单文件上限的文件。
7. 文件名包含中文、Emoji 和 Windows 非法字符语义的样例。

在本机运行 GUI 后扫码或输入验证码即可。不要把验证码、两步验证密码或会话文件发到对话中。

联调检查：聊天列表可见；扫描数量正确；日期、类型、关键词和大小筛选正确；相册成组显示；重复媒体只保存一份；固定清单排除项不会下载；暂停后已完成项跳过、半成品重下；最终文件大小与源样例一致；再次扫描只补齐新增或失败项。
