# TDL Media 0.3.3

- 左侧“全部聊天”后新增“已归档”分组，集中显示 Telegram 中已归档的对话。没有归档对话时显示空状态，入口始终保留。
- “全部聊天”只显示未归档对话，自定义分组继续遵循 Telegram 原有的包含、排除和置顶规则。
- 归档列表支持当前分组内搜索、最近消息排序、名称排序，以及原有的媒体浏览、话题筛选和下载清单。
- 归档状态随聊天目录缓存保存，所选分组按账户记忆。重启后先显示缓存，刷新失败时保留已有内容；加载期间切换分组不会被迟到的偏好设置覆盖。

## 升级

在“设置 → 应用更新”检测更新，或下载 `TDL-Media-windows-x64-0.3.3.zip` 解压使用。账户、索引、规则、任务和下载文件保留。

归档和取消归档在 Telegram 中操作，启动、切换账户或点击“刷新聊天”后同步。旧缓存会在首次成功刷新后完成归档分类。

## 验证

- Go 全量测试、Go vet、26 项前端测试、生产构建和 Tauri Windows 编译通过。
- 覆盖归档筛选、独立置顶顺序、自定义分组、旧缓存、重启恢复、多账户隔离、刷新失败及迟到响应；验证归档聊天的话题浏览和下载清单。
- 1360×850 和 980×650 界面检查通过，无横向溢出；真实账户的归档成员与独立 Telegram API 查询一致。
- 真实账户联调仅读取聊天目录，没有发送消息、下载媒体或修改归档状态。Windows 10 和不同系统缩放比例尚未实测。
