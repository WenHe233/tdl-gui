# TDL Media 0.2.0

- 右键“选择消息”进入多选，支持圆形选择标记、相册整组选中、Shift 连选、全选已加载结果、反选、清空和只看已选。
- 右键增加“从此条开始下载”：将精确时间填入右侧，确认后补扫并开始下载；包含起始消息和同一秒的消息，支持取消扫描。
- 增加已下载和未下载浏览筛选，以及任务文件详情、失败项重试、取消任务、打开所在目录和恢复缺失文件。
- 设置页新增检测更新和一键更新并重启。后续正式版本通过 GitHub Release 便携包更新，先校验 SHA256；替换失败恢复旧程序，保留账户与下载数据。
- 修复筛选前去重导致漏选、话题索引混用、切换聊天后的过期响应、文件冲突、实际路径记录、无日期规则显示和中文账户命名冲突问题。
- 更新引擎安装校验和后台退出处理，补齐多选、扫描、任务恢复、更新校验与回滚测试，并调整右键菜单、相册布局和多选工具栏。

## 下载与升级

下载 `TDL-Media-windows-x64-0.2.0.zip`，解压后运行 `tdl-media-gui.exe`。保留同目录的 `tdl-media.exe`。引擎沿用 tdl v0.20.4。

0.1.x 首次升级到本版需要手动下载；从本版开始可在设置中检测和安装后续版本。默认数据目录仍为 `%APPDATA%\TDL Media`，旧账户、规则和任务可继续使用。旧话题索引需重新扫描以补齐归属。

## 验证范围

自动测试使用本地模拟媒体、下载进程和发布服务器，覆盖超过 100 条媒体的分页、相册选择、同秒边界、话题隔离、扫描失败与取消、文件冲突、失败重试、版本比较、校验失败及更新回滚。

本版未完成真实 Telegram 账户的下载联调，也未在 Windows 10 设备上验证。模拟测试不能代替这些验证。
